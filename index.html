Separate responsibilities. Limit access.

A client enters through the web tier. The web tier calls the application; only the application queries the database. Direct shortcuts are blocked to keep private data private.

Why three tiers?

Separating the web, application and database responsibilities limits the blast radius of an attack and makes each layer easier to secure, scale and understand.
